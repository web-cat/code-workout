## Data Flow

1. User or LTI integration submits a request (e.g. exercise attempt) via the Web UI.
2. The relevant Controller passes input to the Business Logic (Models and Utilities like peml_parsing_util.rb).
3. If it is a code compilation/evaluation, it queues a task in `CodeWorker` (app/jobs/code_worker.rb).
4. Results are processed, persisted into MariaDB, and returned to the UI.
