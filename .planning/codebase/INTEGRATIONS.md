# External Integrations

## Authentication Providers (via OmniAuth)
- Facebook
- Google OAuth2
- CAS (Central Authentication Service)

## Learning Management Systems (LMS) Integration
- **LTI (Learning Tools Interoperability):** Supported via `ims-lti` gem. Used for Canvas integrations (e.g., grading tools, assignment selection).
- **Recent Developments:** Features added for LTI 1.3 Advantage Services, including Assignment and Grades Services (AGS) and Names and Role Provisioning Services (NRPS).

## External APIs & Services
- **Gravatar:** For user profile images (`gravtastic` gem).
- **OpenPOP Support:** Implied by the inclusion of the `rest-client` gem specifically noted for OpenPOP.
